# walkToo BM 정책

## 1. BM 원칙

walkToo의 수익 모델은 **기록을 막고 결제를 유도하는 방식이 아니라, 기록을 더 의미 있는 결과물로 만들어주는 방식**을 따른다.

커플 기록 앱에서 핵심 기록 경험을 제한하면 결제 전환보다 이탈이 먼저 발생할 가능성이 높다. 따라서 산책 기록, 지도, 일정, 메모처럼 앱의 기본 사용 흐름은 무료로 충분히 제공한다.

유료 기능은 다음 기준을 만족해야 한다.

- 사용자가 이미 남긴 기록에서 추가 가치를 만들어준다.
- 결제 후 사용자가 손에 잡히는 결과물을 얻는다.
- 커플 중 한 명만 결제해도 둘이 함께 혜택을 느낄 수 있다.
- 서버 비용이 큰 기능은 무제한 권리로 팔지 않는다.
- 광고 기반 수익화는 도입하지 않는다.

## 2. 지양하는 과금 방식

다음 방식은 walkToo의 톤과 맞지 않으므로 기본 BM으로 사용하지 않는다.

| 방식                | 문제                                      |
| ------------------- | ----------------------------------------- |
| 과거 기록 잠금      | 추억을 볼모로 잡는 느낌이 강함            |
| 지도 보기 잠금      | 앱의 핵심 가치가 약해짐                   |
| 일정/메모 잠금      | 커플 협업 도구로서 신뢰가 떨어짐          |
| 사진 기본 첨부 차단 | 기록 작성 자체를 방해함                   |
| 광고 제거 상품      | 광고 도입 자체가 감성 기록 앱과 맞지 않음 |
| 영구 무제한 저장권  | 스토리지/트래픽 비용이 계속 누적됨        |

## 3. 무료 제공 범위

무료 사용자는 walkToo의 핵심 루프를 충분히 경험할 수 있어야 한다.

무료 범위:

- 하루 기록 작성
- 우리의 기록 / 각자의 기록
- 네이버 지도 기반 추억 마커 보기
- 커플 일정 공유
- 커플 메모 / 체크리스트
- 기본 다이어리 테마
- 기본 포토부스
- 기본 월간 요약
- 커플 연결 및 알림

무료 사용자는 “앱을 제대로 쓰려면 결제해야 한다”가 아니라 “앱이 마음에 들어서 더 예쁘게 남기고 싶다”고 느껴야 한다.

## 4. 유료 상품 방향

유료 상품은 **기능 제한 해제**보다 **추억 결과물 생성**에 집중한다.

### 4.1 추억북 생성권

가장 우선순위가 높은 유료 상품이다.

상품 예시:

- 이름: `우리의 산책북`
- 가격: 3,900원 ~ 6,900원
- 결제 방식: 1회성 소모성 상품
- 제공 결과물: PDF 또는 이미지 앨범

포함 가능 항목:

- 선택 기간의 산책 기록
- 지도 위 추억 마커
- 장소명
- 사진
- 오늘의 질문과 답변
- 메모
- 월별 하이라이트
- 표지 이미지
- 공유용 요약 이미지

운영 정책:

- 생성 요청은 서버에 작업 상태로 저장한다.
- 다운로드 실패 시 다시 받을 수 있어야 한다.
- 생성된 파일은 일정 기간 보관 후 삭제할 수 있다.
- 보관 기간은 결제 전 명확히 고지한다.

### 4.2 기념일 리포트

자연스러운 구매 타이밍이 있는 상품이다.

상품 예시:

- 이름: `100일 리포트`, `1주년 리포트`, `이번 달 우리`
- 가격: 2,900원 ~ 4,900원
- 결제 방식: 1회성 소모성 상품

포함 가능 항목:

- 함께 걸은 장소 수
- 가장 많이 간 장소
- 가장 많이 기록한 달
- 사진 하이라이트
- 서로의 답변 하이라이트
- 지도 기반 추억 카드
- 공유용 이미지

이 상품은 “결제해야 기록을 볼 수 있음”이 아니라 “결제하면 우리 기록을 예쁜 리포트로 만들어줌”으로 포지셔닝한다.

### 4.3 추억 카드 / 포토부스 결과물

가볍게 구매할 수 있는 소액 상품이다.

상품 예시:

- 이름: `추억 카드팩`, `포토부스 프레임팩`
- 가격: 1,100원 ~ 2,200원
- 결제 방식: 1회성 소모성 또는 비소모성 상품

포함 가능 항목:

- 폴라로이드 카드
- 영화 포스터 스타일 카드
- 손편지 스타일 카드
- 인스타 스토리 공유 이미지
- 시즌 프레임

주의점:

- 기본 포토부스는 무료로 유지한다.
- 유료는 결과물의 완성도와 선택지를 늘리는 방향으로 제공한다.

### 4.4 walkToo+ Couple Pass

단일 1회성 이용권이다.

상품 예시:

- 이름: `walkToo+ Couple Pass`
- 가격: 9,900원 얼리버드 또는 14,900원 정가
- 결제 방식: 1회성 비소모성 상품
- 적용 범위: 커플 중 한 명 구매 시 둘 다 적용

제공 방향:

- 구독 없는 커플 이용권
- 추억 결과물 생성 혜택 포함
- 고급 템플릿 제공
- 사진/포토부스/리포트 경험 확장

권장 구성:

| 항목          | 제공                                         |
| ------------- | -------------------------------------------- |
| 커플 공유     | 한 명 구매 시 둘 다 적용                     |
| 사진 첨부     | 우리의 기록 사진 12장까지                    |
| 추억북        | 월 1회 무료가 아니라, 초기에는 1회 포함 권장 |
| 기념일 리포트 | 주요 기념일 리포트 1회 포함 또는 할인        |
| 포토부스      | 고급 프레임/템플릿                           |
| 테마          | 고급 다이어리 테마                           |
| 구매 복원     | 동일 스토어 계정에서 복원                    |

주의점:

- “평생”, “영구”, “무제한 저장” 표현은 사용하지 않는다.
- “서비스 제공 기간 동안”, “구독 없는 1회성 구매”, “구매 계정에 적용”처럼 안전한 표현을 사용한다.
- 서버 비용이 계속 누적되는 기능은 Couple Pass에 무제한으로 포함하지 않는다.

## 5. 가격 정책

초기 목표는 대규모 매출이 아니라 서버비와 1인 운영 비용을 감당하는 부업형 수익이다.

권장 가격:

| 상품                          |              가격 |
| ----------------------------- | ----------------: |
| 추억 카드 / 프레임팩          | 1,100원 ~ 2,200원 |
| 기념일 리포트                 | 2,900원 ~ 4,900원 |
| 산책북 생성권                 | 3,900원 ~ 6,900원 |
| walkToo+ Couple Pass 얼리버드 |           9,900원 |
| walkToo+ Couple Pass 정가     |          14,900원 |

초기에는 상품을 많이 만들기보다 다음 순서로 검증한다.

1. `우리의 산책북`
2. `walkToo+ Couple Pass`
3. `기념일 리포트`
4. `추억 카드 / 포토부스 프레임팩`

## 6. 서버비 관점 정책

서버 비용이 커지는 요소:

- 사진 원본 저장
- 이미지 다운로드 트래픽
- PDF/ZIP 생성
- 대용량 백업 파일 보관
- 지도/외부 API 호출

정책:

- 원본 무제한 보관을 약속하지 않는다.
- 결과물 생성 파일은 보관 기간을 둔다.
- 큰 파일 다운로드는 재시도 가능한 작업 단위로 관리한다.
- 결제 성공과 파일 생성 성공을 분리해서 추적한다.
- 생성 실패 시 재생성 또는 환불 대응이 가능해야 한다.

대용량 결과물 처리 권장 흐름:

1. 사용자가 결제한다.
2. 서버에 `export_job`을 생성한다.
3. 앱은 “생성 중” 상태를 보여준다.
4. 생성 완료 후 다운로드 버튼을 제공한다.
5. 다운로드 실패 시 같은 결과물을 다시 받을 수 있다.
6. 보관 만료일을 표시한다.

## 7. Paywall 문구 원칙

좋은 문구:

- “우리 기록을 산책북으로 만들어드려요”
- “구독 없이 한 번만 결제해요”
- “한 명만 구매해도 둘 다 사용할 수 있어요”
- “기기를 바꿔도 구매를 복원할 수 있어요”
- “사진과 답변을 예쁜 결과물로 정리해요”

피해야 할 문구:

- “영구 사용”
- “평생 이용권”
- “무제한 저장”
- “광고 제거”
- “결제하지 않으면 기록을 볼 수 없어요”

## 8. 현재 앱에 바로 적용할 BM

현재 기능 기준으로 가장 자연스러운 적용안:

무료:

- 기록 작성
- 지도 보기
- 일정/메모
- 기본 사진 첨부
- 기본 포토부스
- 기본 테마

첫 결과물 상품:

- `우리의 산책북` PDF 또는 이미지 앨범 생성권
- 기간 선택 + 표지 + 다운로드 재시도에 집중한 좁은 MVP
- 앱의 paywall에서 바로 산책북 만들기 흐름으로 진입

walkToo+ Couple Pass:

- 우리의 기록 사진 12장
- 고급 포토부스 프레임
- 고급 다이어리 테마
- 산책북 생성권 1회 포함
- 기념일 리포트 할인 또는 1회 포함
- 커플 둘 다 적용

추가 1회성 상품:

- 산책북 생성권
- 기념일 리포트 생성권
- 포토부스 프레임팩

## 9. 운영 목표

초기 목표는 큰 매출이 아니라 다음 수준을 현실적으로 달성하는 것이다.

| 목표                  | 필요한 결제 규모 |
| --------------------- | ---------------: |
| 월 서버비 5만원 커버  |         월 4~6건 |
| 월 서버비 15만원 커버 |       월 12~18건 |
| 월 50만원 부업 수익   |       월 40~60건 |
| 월 100만원 부업 수익  |      월 80~120건 |

따라서 초기 전략은 대규모 마케팅보다 다음에 집중한다.

- 실제 커플 10~30쌍의 반복 사용
- 기록이 쌓인 뒤 구매하고 싶은 결과물 검증
- 기념일/월말처럼 구매 타이밍이 있는 화면 설계
- 결제 후 실패하지 않는 안정적인 결과물 생성

## 10. 결론

walkToo의 BM은 “제약 해제”가 아니라 **추억 결과물 판매**가 되어야 한다.

무료 사용자는 매일 기록하고, 지도에서 추억을 보고, 일정과 메모를 공유할 수 있어야 한다. 유료 사용자는 그 기록을 산책북, 기념일 리포트, 공유 카드처럼 더 예쁜 결과물로 받을 수 있어야 한다.

이 방향이 커플 앱의 감성과 맞고, 1인 운영자가 서버비와 부업 수익을 관리하기에도 가장 현실적이다.
