# walkToo BM 정책

## 1. 원칙

walkToo는 기록을 막고 결제를 유도하지 않는다. 기본 기록 경험은 무료로 충분히 제공하고, 유료는 "오늘 기록을 더 예쁘게, 더 오래, 더 많이 남기는 선택지"와 "쌓인 기록을 다시 꺼내는 결과물"로 둔다.

무료로 유지한다.

- 산책/각자 기록 작성
- 과거 기록 열람
- 지도, 캘린더, 커플 메모
- 기본 사진 첨부
- 3초 짧은 영상
- 기본 다이어리 테마
- 기본 포토부스
- 커플 연결과 알림

초기에는 광고를 넣지 않는다. 커플 기록 앱에서 광고는 감정적 몰입을 끊고, 광고 제거 상품은 앱의 톤과 맞지 않는다.

## 2. 지양하는 방식

| 방식 | 이유 |
| --- | --- |
| 과거 기록 잠금 | 추억을 볼모로 잡는 느낌이 강함 |
| 지도/캘린더/메모 잠금 | 앱의 핵심 사용 이유가 약해짐 |
| 기본 기록 수 제한 | 습관 형성 전에 이탈 가능성이 큼 |
| 사진 기본 첨부 차단 | 기록 작성 자체를 방해함 |
| 광고 제거 상품 | 광고 도입 자체가 감성 기록 앱과 맞지 않음 |
| 구독 강제 | 초기 커플 앱에는 심리 부담이 큼 |
| 영구 무제한 저장 약속 | 스토리지/트래픽 비용이 누적됨 |

## 3. 초기 유료 상품

초기 상품은 기록 업그레이드, 테마팩, 결과물 생성권의 3개 축으로 둔다. 상품 수를 무리하게 늘리기보다, 결제 순간이 자연스러운지 먼저 검증한다.

### 3.1 기록 업그레이드

첫 출시에서 가장 먼저 붙일 상품이다.

| 항목 | 정책 |
| --- | --- |
| 결제 | 구독 없는 1회성 비소모성 IAP |
| 가격 | 3,300원 |
| 적용 | 구매한 커플 양쪽 적용 |
| 무료 기준 | 사진 4장, 영상 3초 |
| 업그레이드 | 사진 8장, 영상 5초 |

다이어리 테마는 기록 업그레이드에 포함하지 않는다. 테마는 별도 단건 상품(여행 무드 테마팩)으로 판다 — 3.2 참고.

2,200원은 출시 초반 프로모션으로만 쓴다. 기본 기준가는 3,300원으로 두어 커플 공유 1회성 상품의 LTV 하한을 지킨다.

포지셔닝:

- "기록하려면 결제"가 아니라 "특별한 날만 더 풍성하게"
- 사진 4장을 초과하려 할 때
- 3초 영상에서 5초로 늘리고 싶을 때

좋은 문구:

- "오늘 기록을 조금 더 길게 남겨볼까요?"
- "기본은 무료예요. 특별한 날만 업그레이드해요."
- "구독 없이 한 번만 결제해요."

피할 문구:

- "프리미엄 회원"
- "평생 이용권"
- "무제한"
- "결제하지 않으면 저장할 수 없어요"

### 3.2 다이어리 테마팩

별도 단건 비소모성 상품으로 판다 (구독 없음, 커플 한 명 결제 시 양쪽 적용).

현재 상품 — **여행 무드 테마팩**:

| 항목 | 정책 |
| --- | --- |
| 가격 | 3,300원 (fallback, 스토어 가격이 기준) |
| 포함 테마 | 삿포로 필름, 홍콩 야경, 마지막 공항 |
| Product ID | `com.walktoo.theme_pack_travel` |
| Entitlement ID | `walktoo_theme_pack_travel` |

게이팅 원칙:

- **새 선택만 잠근다.** 이미 저장된 다이어리의 테마 표시는 절대 게이팅하지 않는다 (추억 볼모 금지).
- 잠긴 테마는 ThemePicker에서 잠금 배지로 보이고, 미리보기는 항상 가능하다.
- 구매 진입점은 ThemePicker 하단 카드 1곳 — 다른 화면에서 팝업으로 밀지 않는다.

향후 팩 후보 (구매 신호 확인 후):

- 계절 테마팩 (연 2~3회 출시 — 반복 구매 거리)
- 러브레터팩

무료 테마도 충분히 예뻐야 한다. 유료 테마는 작성 기능이 아니라 취향과 소장욕을 확장하는 상품이다.

### 3.3 추억 카드 / 산책북

기록이 쌓인 뒤 가장 건강한 수익원이 될 수 있다.

| 상품 | 가격 후보 |
| --- | ---: |
| 추억 카드 이미지 | 1,500원 |
| 포토부스 프레임팩 | 1,500원 ~ 2,200원 |
| 기념일 리포트 | 5,900원 |
| 산책북 PDF/이미지 앨범 | 기본 6,900원 / 긴 기간 8,900원 |

이 상품은 "기록을 보려면 결제"가 아니라 "이미 쌓인 기록을 예쁘게 꺼내는 결제"로 설계한다.

결과물 상품은 서버 생성/저장 비용이 직접 붙는다. 결제 성공, 생성 성공, 재다운로드 가능 기간, 실패 시 재생성/환불 대응을 분리해서 추적한다.

## 4. 가격 손익 기준

기록 업그레이드와 테마팩만으로 인건비 BEP를 맞추려고 하면 무리가 크다. 이 둘은 첫 결제 장벽을 낮추고 구매 저항을 검증하는 상품이며, 실제 매출 축은 추억 카드, 산책북, 기념일 리포트 같은 결과물 상품이 맡아야 한다.

15% 스토어 수수료와 부가세를 보수적으로 반영하면 대략 다음 수준으로 본다.

| 상품 | 소비자가 | 앱 실수령 기준 |
| --- | ---: | ---: |
| 기록 업그레이드 | 3,300원 | 약 2,550원 |
| 여행 무드 테마팩 | 3,300원 | 약 2,550원 |
| 기록+테마 묶음 기준 | 5,900원 | 약 4,560원 |
| 산책북 기본 | 6,900원 | 약 5,330원 |

운영 판단:

- 월 100만 원 수준의 서버/툴 비용은 소액 상품만으로도 방어 가능하다.
- 1명 인건비 또는 2인 팀 인건비까지 포함하면 1회성 업그레이드만으로는 부족하다.
- 핵심 무료 루프는 유지하되, 기록이 쌓인 뒤 반복 구매할 이유가 있는 결과물 상품을 우선 구현한다.

## 5. 현재 앱 적용안

코드 기준 현재 적용한다.

- 무료 사진 한도: 4장
- 업그레이드 사진 한도: 8장
- 무료 짧은 영상: 3초
- 업그레이드 짧은 영상: 5초
- 무료 다이어리 테마: 후쿠오카 골목(y2k_pastel), 방콕 야시장(pixel_retro), 타이완 노트(grid_minimal)
- 여행 무드 테마팩: 삿포로 필름(vintage_film), 홍콩 야경(dreamy_cloud), 마지막 공항(dark_academia)
- 기록 업그레이드 가격 fallback: 3,300원 / 테마팩: 3,300원
- 결과물 가격 기준: 추억 카드 1,500원 / 산책북 기본 6,900원 / 산책북 긴 기간 8,900원 / 기념일 리포트 5,900원
- Product ID: `com.walktoo.record_upgrade` / `com.walktoo.theme_pack_travel`
- Entitlement ID: `walktoo_record_upgrade` / `walktoo_theme_pack_travel`

기본 기록 수는 제한하지 않는다. 기록 수 제한은 습관 형성을 방해하므로 초기 BM에서 제외한다.

## 6. 결제 노출 위치

홈 첫 화면에서 강하게 팔지 않는다. 사용자가 이미 기록 의도를 가진 순간에만 노출한다.

- 영상 모드에서 "5초 영상 업그레이드"
- 사진 4장 초과 시도
- 고급 다이어리 테마 선택
- 저장 후 추억 카드 만들기
- 산책북/기념일 리포트 화면
- 출시 프로모션이 필요한 경우에만 2,200원 업그레이드가를 짧게 노출하고, 기본 기준가는 3,300원으로 되돌린다

## 7. 운영 목표

초기 목표는 MRR이 아니라 구매 저항이 낮은 1회성 상품을 찾는 것이다.

- 7일/30일 기록 지속률
- 사진 4장 초과 시도율
- 영상 모드 진입률과 5초 업그레이드 클릭률
- 고급 테마 탭률
- 산책북 가격표 노출 대비 생성 시도율
- 결과물 구매 후 공유/재방문률
- paywall 진입 대비 구매 전환율
- 결제 후 기록 저장 성공률

## 8. 결론

walkToo의 초기 BM은 광고와 구독 없이 간다. 무료 사용자는 매일 기록하고, 지도에서 추억을 보고, 일정과 메모를 공유할 수 있어야 한다. 유료는 특별한 날의 기록을 더 풍성하게 만드는 1회성 업그레이드에서 시작하되, BEP는 추억 카드와 산책북 같은 결과물 상품으로 맞춘다.
