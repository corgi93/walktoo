# walkToo BM 정책

## 1. 원칙

walkToo는 기록을 막고 결제를 유도하지 않는다. 기본 기록 경험은 무료로 충분히 제공하고, 유료는 "오늘 기록을 더 예쁘게, 더 오래, 더 많이 남기는 선택지"로 둔다.

무료로 유지한다.

- 산책/각자 기록 작성
- 과거 기록 열람
- 지도, 캘린더, 커플 메모
- 기본 사진 첨부
- 3초 짧은 영상
- 기본 다이어리 테마
- 기본 포토부스
- 커플 연결과 알림

초기에는 광고를 넣지 않는다. 커플 기록 앱에서 광고는 감정적 몰입을 끊고, 광고 제거 상품은 앱의 톤과 맞지 않는다.

## 2. 지양하는 방식

| 방식 | 이유 |
| --- | --- |
| 과거 기록 잠금 | 추억을 볼모로 잡는 느낌이 강함 |
| 지도/캘린더/메모 잠금 | 앱의 핵심 사용 이유가 약해짐 |
| 기본 기록 수 제한 | 습관 형성 전에 이탈 가능성이 큼 |
| 사진 기본 첨부 차단 | 기록 작성 자체를 방해함 |
| 광고 제거 상품 | 광고 도입 자체가 감성 기록 앱과 맞지 않음 |
| 구독 강제 | 초기 커플 앱에는 심리 부담이 큼 |
| 영구 무제한 저장 약속 | 스토리지/트래픽 비용이 누적됨 |

## 3. 초기 유료 상품

초기 상품은 3개만 둔다. 상품 수를 늘리기보다, 결제 순간이 자연스러운지 먼저 검증한다.

### 3.1 기록 업그레이드

첫 출시에서 가장 먼저 붙일 상품이다.

| 항목 | 정책 |
| --- | --- |
| 결제 | 구독 없는 1회성 비소모성 IAP |
| 가격 | 2,200원 |
| 적용 | 구매한 커플 양쪽 적용 |
| 무료 기준 | 사진 4장, 영상 3초, 기본 테마 |
| 업그레이드 | 사진 8장, 영상 5초, 고급 다이어리 테마 |

포지셔닝:

- "기록하려면 결제"가 아니라 "특별한 날만 더 풍성하게"
- 사진 4장을 초과하려 할 때
- 3초 영상에서 5초로 늘리고 싶을 때
- 고급 테마를 탭할 때

좋은 문구:

- "오늘 기록을 조금 더 길게 남겨볼까요?"
- "기본은 무료예요. 특별한 날만 업그레이드해요."
- "구독 없이 한 번만 결제해요."

피할 문구:

- "프리미엄 회원"
- "평생 이용권"
- "무제한"
- "결제하지 않으면 저장할 수 없어요"

### 3.2 다이어리 테마팩

현재는 `기록 업그레이드` 안에 포함해 시작한다. 구매 신호가 확인되면 별도 테마팩으로 분리할 수 있다.

가능한 팩:

- 레트로 픽셀팩
- 빈티지 필름팩
- 러브레터팩
- 계절 테마팩

가격 후보:

- 개별 테마팩 1,100원 ~ 2,200원
- 묶음팩 3,900원

무료 테마도 충분히 예뻐야 한다. 유료 테마는 작성 기능이 아니라 취향과 소장욕을 확장하는 상품이다.

### 3.3 추억 카드 / 산책북

기록이 쌓인 뒤 가장 건강한 수익원이 될 수 있다.

| 상품 | 가격 후보 |
| --- | ---: |
| 추억 카드 이미지 | 1,100원 |
| 포토부스 프레임팩 | 1,100원 ~ 2,200원 |
| 기념일 리포트 | 2,900원 ~ 4,900원 |
| 산책북 PDF/이미지 앨범 | 3,900원 ~ 6,900원 |

이 상품은 "기록을 보려면 결제"가 아니라 "이미 쌓인 기록을 예쁘게 꺼내는 결제"로 설계한다.

## 4. 현재 앱 적용안

코드 기준 현재 적용한다.

- 무료 사진 한도: 4장
- 업그레이드 사진 한도: 8장
- 무료 짧은 영상: 3초
- 업그레이드 짧은 영상: 5초
- 무료 다이어리 테마: Y2K 파스텔, 픽셀 레트로, 그리드 미니멀
- 업그레이드 테마: 빈티지 필름, 드리미 클라우드, 다크 아카데미아
- 가격 fallback: 2,200원
- Product ID: `com.walktoo.record_upgrade`
- Entitlement ID: `walktoo_record_upgrade`

기본 기록 수는 제한하지 않는다. 기록 수 제한은 습관 형성을 방해하므로 초기 BM에서 제외한다.

## 5. 결제 노출 위치

홈 첫 화면에서 강하게 팔지 않는다. 사용자가 이미 기록 의도를 가진 순간에만 노출한다.

- 영상 모드에서 "5초 영상 업그레이드"
- 사진 4장 초과 시도
- 고급 다이어리 테마 선택
- 저장 후 추억 카드 만들기
- 산책북/기념일 리포트 화면

## 6. 운영 목표

초기 목표는 MRR이 아니라 구매 저항이 낮은 1회성 상품을 찾는 것이다.

- 7일/30일 기록 지속률
- 사진 4장 초과 시도율
- 영상 모드 진입률과 5초 업그레이드 클릭률
- 고급 테마 탭률
- paywall 진입 대비 구매 전환율
- 결제 후 기록 저장 성공률

## 7. 결론

walkToo의 초기 BM은 광고와 구독 없이 간다. 무료 사용자는 매일 기록하고, 지도에서 추억을 보고, 일정과 메모를 공유할 수 있어야 한다. 유료는 특별한 날의 기록을 더 풍성하게 만드는 1회성 업그레이드에서 시작하고, 이후 추억 카드와 산책북 같은 결과물 상품으로 확장한다.
