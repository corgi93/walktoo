# walkToo BM 정책

## 1. 원칙

walkToo는 기록을 막고 결제를 유도하지 않는다. 기본 기록 경험은 무료로 충분히 제공하고, 유료는 "오늘 기록을 더 예쁘게, 더 오래, 더 많이 남기는 선택지"와 "쌓인 기록을 다시 꺼내는 결과물"로 둔다.

walkToo의 핵심 기록 단위는 `투로그(TooLog)`다. 투로그는 네컷 같은 특정 레이아웃명이 아니라, 둘이 각자 남긴 사진 또는 짧은 영상, 최대 30자의 한마디, 날짜, 장소, 걸음수가 합쳐져 열리는 하루 기록이다.

텍스트 정책:

- 한마디는 최대 30자까지만 받는다.
- 최소 글자 수는 강제하지 않는다.
- 비워도 저장할 수 있고, 추천 문구를 눌러 가볍게 채울 수 있게 한다.
- 긴 일기 입력은 별도 다이어리 화면에 남겨두고, 투로그에서는 부담을 줄인다.

걸음수는 만보기 앱처럼 독립 상품으로 세우지 않는다. 오늘의 투로그를 더 구체적으로 만드는 메타 정보와 보조 습관 장치로 쓴다.

무료로 유지한다.

- 산책/각자 기록 작성
- 오늘의 투로그 작성과 열람
- 과거 기록 열람
- 지도, 캘린더, 커플 메모
- 기본 사진 첨부
- 3초 짧은 영상
- 기본 다이어리 테마
- 기본 투로그 프레임
- 커플 연결과 알림

초기에는 광고를 넣지 않는다. 커플 기록 앱에서 광고는 감정적 몰입을 끊고, 광고 제거 상품은 앱의 톤과 맞지 않는다.

## 2. 지양하는 방식

| 방식 | 이유 |
| --- | --- |
| 과거 기록 잠금 | 추억을 볼모로 잡는 느낌이 강함 |
| 지도/캘린더/메모 잠금 | 앱의 핵심 사용 이유가 약해짐 |
| 기본 기록 수 제한 | 습관 형성 전에 이탈 가능성이 큼 |
| 사진 기본 첨부 차단 | 기록 작성 자체를 방해함 |
| 광고 제거 상품 | 광고 도입 자체가 감성 기록 앱과 맞지 않음 |
| 구독 강제 | 초기 커플 앱에는 심리 부담이 큼 |
| 기간·범위 없는 무제한 저장 약속 | 스토리지/트래픽 비용이 누적됨 |

## 3. 초기 유료 상품

초기 상품은 커플 패스, 테마팩, 결과물 생성권의 3개 축으로 둔다. 상품 수를 무리하게 늘리기보다, 투로그가 매일 반복되는지와 결제 순간이 자연스러운지 먼저 검증한다.

### 3.1 커플 패스 1년

첫 출시에서 가장 먼저 붙일 상품이다.

| 항목 | 정책 |
| --- | --- |
| 결제 | 자동 갱신 없는 12개월 패스 |
| 가격 | 9,900원 |
| 적용 | 구매일 기준 현재 연결된 커플 양쪽 적용 |
| 무료 기준 | 사진 4장, 영상 3초 |
| 패스 혜택 | 사진 8장, 영상 5초 |

다이어리 테마는 커플 패스에 포함하지 않는다. 테마는 별도 단건 상품(여행 무드 테마팩)으로 판다 — 3.2 참고.

커플 공유 영구형 상품은 쓰지 않는다. 커플 1쌍이 1년 동안 함께 쓰는 기준가는 9,900원으로 두고, 기간 없는 무제한 권리가 아니라 12개월 패스로 운영한다. 초기에는 낮은 진입가로 결제 저항을 줄이고, 투로그 카드·투로그북·테마팩 같은 소액 결과물로 객단가를 쌓는다.

포지셔닝:

- "기록하려면 결제"가 아니라 "특별한 날만 더 풍성하게"
- 사진 4장을 초과하려 할 때
- 3초 영상에서 5초로 늘리고 싶을 때
- 자동 갱신이 없어 부담은 낮추되, 기간 없는 무제한 권리로 팔지 않는다

좋은 문구:

- "오늘 기록을 조금 더 길게 남겨볼까요?"
- "기본 기록은 무료예요. 커플 패스는 특별한 날의 표현을 1년 동안 넓혀줘요."
- "자동 갱신 없이 12개월 동안 둘이 함께 써요."
- "기간이 끝나면 직접 다시 연장할 수 있어요."

피할 문구:

- "프리미엄 회원"
- "무제한"
- "결제하지 않으면 저장할 수 없어요"
- "평생 이용"
- "무료 업그레이드"
- "환불 불가"

### 3.2 다이어리 테마팩

별도 단건 비소모성 상품으로 판다 (구독 없음, 커플 한 명 결제 시 양쪽 적용).

현재 상품 — **여행 무드 테마팩**:

| 항목 | 정책 |
| --- | --- |
| 가격 | 3,300원 (fallback, 스토어 가격이 기준) |
| 포함 테마 | 삿포로 필름, 홍콩 야경, 도쿄 레코드샵 |
| Product ID | `com.walktoo.theme_pack_travel` |
| Entitlement ID | `walktoo_theme_pack_travel` |

게이팅 원칙:

- **새 선택만 잠근다.** 이미 저장된 다이어리의 테마 표시는 절대 게이팅하지 않는다 (추억 볼모 금지).
- 잠긴 테마는 ThemePicker에서 잠금 배지로 보이고, 미리보기는 항상 가능하다.
- 구매 진입점은 ThemePicker 하단 카드 1곳 — 다른 화면에서 팝업으로 밀지 않는다.

향후 팩 후보 (구매 신호 확인 후):

- 계절 테마팩 (연 2~3회 출시 — 반복 구매 거리)
- 러브레터팩

무료 테마도 충분히 예뻐야 한다. 유료 테마는 작성 기능이 아니라 취향과 소장욕을 확장하는 상품이다.

### 3.3 투로그 카드 / 투로그북

기록이 쌓인 뒤 가장 건강한 수익원이 될 수 있다.

| 상품 | 가격 후보 |
| --- | ---: |
| 커플 패스+여행 테마팩 | 11,000원 |
| 투로그 카드 이미지 | 1,500원 |
| 투로그 프레임팩 | 1,500원 ~ 2,200원 |
| 기념일 리포트 | 5,900원 |
| 투로그북 PDF/이미지 앨범 | 기본 6,900원 / 긴 기간 8,900원 |

이 상품은 "기록을 보려면 결제"가 아니라 "이미 쌓인 기록을 예쁘게 꺼내는 결제"로 설계한다.

결과물 상품은 서버 생성/저장 비용이 직접 붙는다. 결제 성공, 생성 성공, 재다운로드 가능 기간, 실패 시 재생성/환불 대응을 분리해서 추적한다.

커플 패스+테마팩 묶음은 보류 상품이다. 커플 패스는 12개월 만료, 테마팩은 영구 권리라 두 entitlement를 분리 동기화하는 구현이 붙기 전에는 스토어에 등록하지 않는다.

## 4. 가격 손익 기준

커플 패스와 테마팩만으로 인건비 BEP를 맞추려고 하면 무리가 크다. 이 둘은 첫 결제 장벽과 연간 지불 의사를 검증하는 상품이며, 실제 매출 축은 투로그 카드, 투로그북, 기념일 리포트 같은 결과물 상품이 맡아야 한다.

15% 스토어 수수료와 부가세를 보수적으로 반영하면 대략 다음 수준으로 본다.

| 상품 | 소비자가 | 앱 실수령 기준 |
| --- | ---: | ---: |
| 커플 패스 1년 | 9,900원 | 약 7,650원 |
| 여행 무드 테마팩 | 3,300원 | 약 2,550원 |
| 커플 패스+테마팩 묶음 기준 | 11,000원 | 약 8,500원 |
| 투로그북 기본 | 6,900원 | 약 5,330원 |

운영 판단:

- 월 100만 원 수준의 서버/툴 비용은 소액 상품만으로도 방어 가능하다.
- 1명 인건비 또는 2인 팀 인건비까지 포함하면 커플 패스만으로는 부족하다.
- 핵심 무료 루프는 유지하되, 투로그가 쌓인 뒤 반복 구매할 이유가 있는 결과물 상품을 우선 구현한다.

## 5. 현재 앱 적용안

코드 기준 현재 적용한다.

- 무료 사진 한도: 4장
- 커플 패스 사진 한도: 8장
- 무료 짧은 영상: 3초
- 커플 패스 짧은 영상: 5초
- 무료 다이어리 테마: 후쿠오카 골목(y2k_pastel), 방콕 야시장(pixel_retro), 타이완 노트(grid_minimal)
- 여행 무드 테마팩: 삿포로 필름(vintage_film), 홍콩 야경(dreamy_cloud), 도쿄 레코드샵(dark_academia)
- 커플 패스 가격 fallback: 9,900원 / 테마팩: 3,300원
- 커플 패스+테마팩 묶음 기준: 11,000원
- 결과물 가격 기준: 투로그 카드 1,500원 / 투로그북 기본 6,900원 / 투로그북 긴 기간 8,900원 / 기념일 리포트 5,900원
- Product ID: `com.walktoo.couple_pass_annual` / `com.walktoo.theme_pack_travel`
- Android RevenueCat Product ID: `com.walktoo.couple_pass_annual:annual_prepaid`
- Entitlement ID: `walktoo_couple_pass` / `walktoo_theme_pack_travel`

기본 기록 수는 제한하지 않는다. 기록 수 제한은 습관 형성을 방해하므로 초기 BM에서 제외한다.

## 6. 결제 노출 위치

홈 첫 화면에서 강하게 팔지 않는다. 사용자가 이미 기록 의도를 가진 순간에만 노출한다.

- 영상 모드에서 "5초 영상 커플 패스"
- 사진 4장 초과 시도
- 고급 다이어리 테마 선택
- 저장 후 투로그 카드 만들기
- 투로그북/기념일 리포트 화면
- 출시 프로모션이 필요한 경우에도 "평생", "무료", "환불 불가" 표현은 쓰지 않는다

## 7. 운영 목표

초기 목표는 강제 구독 MRR이 아니라 부담이 낮은 12개월 패스와 결과물 상품의 구매 신호를 찾는 것이다.

- 7일/30일 기록 지속률
- 오늘의 투로그 작성률
- 둘 다 작성 후 공개율
- 사진 4장 초과 시도율
- 영상 모드 진입률과 5초 커플 패스 클릭률
- 고급 테마 탭률
- 투로그북 가격표 노출 대비 생성 시도율
- 결과물 구매 후 공유/재방문률
- paywall 진입 대비 구매 전환율
- 결제 후 기록 저장 성공률

## 8. 결론

walkToo의 초기 BM은 광고와 자동 갱신 구독 없이 간다. 무료 사용자는 매일 투로그를 남기고, 지도에서 추억을 보고, 일정과 메모를 공유할 수 있어야 한다. 유료는 특별한 날의 기록을 더 풍성하게 만드는 12개월 커플 패스에서 시작하되, BEP는 투로그 카드와 투로그북 같은 결과물 상품으로 맞춘다.
