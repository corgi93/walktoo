# walkToo 비즈니스 플랜

이 문서는 walkToo의 사업 방향과 실행 순서를 요약한다. 과금 정책의 source of truth는
`docs/bm-policy.md`이며, 가격과 상품 표현을 바꿀 때는 이 문서와 함께 갱신한다.

## 1. 서비스 개요

- **앱 이름**: walkToo
- **카테고리**: 커플 산책 다이어리
- **핵심 가치**: 각자의 하루와 함께 보낸 산책을 기록하고, 둘의 추억을 다시 꺼내 보는 경험
- **기술 스택**: React Native (Expo) + Supabase

## 2. 수익 모델

walkToo는 핵심 기록 루프를 무료로 유지한다.

무료 범위:

- 하루 기록 작성
- 우리의 기록 / 각자의 기록
- 지도 위 추억 보기
- 일정과 커플 메모
- 기본 사진 첨부
- 기본 다이어리 테마와 포토부스
- 커플 연결과 알림

유료는 기록 접근권을 파는 방식이 아니라 특별한 날의 표현력을 넓히고, 이미 쌓인 기록에서 더 예쁜 결과물을 만드는 방식에 집중한다.

우선순위:

1. `커플 패스 1년`
2. 다이어리 테마 / 스티커 / 포토부스 프레임팩
3. 추억 카드
4. `우리의 산책북` PDF 또는 이미지 앨범 생성권

지양하는 방식:

- 과거 기록 잠금
- 지도, 일정, 메모 같은 핵심 흐름 잠금
- 광고 제거 상품
- 기간·범위 없는 무제한 저장 약속
- 결제하지 않으면 기록을 볼 수 없다는 톤

## 3. 상품 방향

### 커플 패스 1년

첫 번째 결제 상품은 부담이 낮아야 한다.

| 항목 | 정책 |
| --- | --- |
| 결제 | 자동 갱신 없는 12개월 패스 |
| 가격대 | 기본 8,800원 |
| 무료 기준 | 사진 4장, 영상 3초 |
| 패스 혜택 | 사진 8장, 영상 5초 |
| 노출 위치 | 사진 한도 도달, 5초 영상 선택 |

핵심 기록 수는 제한하지 않는다. 결제는 특별한 날의 표현력을 넓히는 순간에만 노출한다. `평생`, `무료 업그레이드`, `환불 불가` 표현은 쓰지 않고, 구매일로부터 12개월·자동 갱신 없음·스토어 환불 정책을 명시한다.

### 우리의 산책북

산책북은 기록이 충분히 쌓인 뒤 붙이는 결과물 상품이다.

| 항목 | 정책 |
| --- | --- |
| 결과물 | 선택 기간의 PDF 또는 이미지 앨범 |
| 결제 | 1회성 생성권 |
| 가격대 | 기본 6,900원 / 긴 기간 8,900원 |
| 포함 데이터 | 장소, 사진, 질문 답변, 메모, 추억 지도 요약 |
| 운영 | 생성 작업 상태, 재다운로드, 보관 만료일을 명시 |

초기 버전은 한 번에 모든 편집 기능을 넣지 않는다. 기간 선택, 표지, 기록 요약,
다운로드 재시도처럼 결과물 전달에 필요한 흐름부터 검증한다.

## 4. 가격 기준

| 상품 | 현재 기준 |
| --- | ---: |
| 커플 패스 1년 fallback | 8,800원 |
| 여행 무드 테마팩 | 3,300원 |
| 커플 패스+테마팩 묶음 기준 | 11,000원 |
| 추억 카드 이미지 | 1,500원 |
| 우리의 산책북 생성권 | 기본 6,900원 / 긴 기간 8,900원 |
| 기념일 리포트 | 5,900원 |
| 포토부스 프레임팩 | 1,500원 ~ 2,200원 |

BEP 관점에서 커플 패스와 테마팩은 운영비 일부를 방어하는 입구 상품이다. 커플 패스는 8,800원으로 진입 장벽을 낮추고, 인건비까지 포함한 손익은 산책북, 기념일 리포트, 추억 카드처럼 반복 구매가 가능한 결과물 상품으로 맞춘다.

커플 패스 가격을 바꾸면 다음을 같은 작업에서 맞춘다.

1. `src/constants/premium.ts`
2. `docs/revenuecat-setup.md`
3. `docs/bm-policy.md`
4. Apple App Store Connect
5. Google Play Console
6. RevenueCat offering

## 5. 결제 운영

IAP는 RevenueCat을 사용한다. 클라이언트는 결제 성공 후 entitlement를 Supabase에
동기화하고, 운영 안정성이 필요해지면 RevenueCat webhook 기반 서버 동기화로 옮긴다.

결과물 상품은 결제 성공과 파일 생성 성공을 분리해서 추적한다.

1. 결제 또는 생성권 사용
2. 서버 export job 생성
3. 앱에서 생성 중 상태 표시
4. 완료 후 다운로드 제공
5. 실패 시 재생성 또는 환불 대응

## 6. 초기 실행 순서

1. BM 문서와 콘솔 상품 표현을 결과물 중심으로 정렬한다.
2. 사진 한도, 5초 영상, 고급 테마에서만 paywall을 노출한다.
3. 추억 카드 저장 흐름을 붙여 소액 결과물 구매를 검증한다.
4. 산책북 기본 생성권을 먼저 붙여 6,900원 가격 저항을 확인한다.
5. 실제 커플 10~30쌍에게 커플 패스 클릭/구매 이유를 확인한다.
6. 반응이 확인된 뒤 긴 기간 산책북과 기념일 리포트를 확장한다.

## 7. KPI

초기에는 구독 MRR보다 결과물 구매 신호를 먼저 본다.

- 7일/30일 기록 지속률
- 사진 4장 초과 시도율
- 5초 영상 커플 패스 클릭률
- 고급 테마 탭률
- 추억 카드 진입률
- 산책북 가격표 노출 대비 생성 시도율
- 결과물 재다운로드 실패율
- 결과물 구매 후 공유/재방문률
- 실제 커플 피드백에서 반복되는 구매 이유

## 8. 결론

walkToo는 추억을 잠가 결제시키지 않는다. 기록은 무료로 쌓이고, 유료는 그 기록을
더 풍성하게 꾸미고, 추억 카드와 산책북처럼 다시 갖고 싶은 결과물로 바꿔주는 데 집중한다.
