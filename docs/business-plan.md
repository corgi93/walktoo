# walkToo 비즈니스 플랜

이 문서는 walkToo의 사업 방향과 실행 순서를 요약한다. 과금 정책의 source of truth는
`docs/bm-policy.md`이며, 가격과 상품 표현을 바꿀 때는 이 문서와 함께 갱신한다.

## 1. 서비스 개요

- **앱 이름**: walkToo
- **카테고리**: 커플 산책 다이어리
- **핵심 가치**: 각자의 하루와 함께 보낸 산책을 기록하고, 둘의 추억을 다시 꺼내 보는 경험
- **기술 스택**: React Native (Expo) + Supabase

## 2. 수익 모델

walkToo는 핵심 기록 루프를 무료로 유지한다.

무료 범위:

- 하루 기록 작성
- 우리의 기록 / 각자의 기록
- 지도 위 추억 보기
- 일정과 커플 메모
- 기본 사진 첨부
- 기본 다이어리 테마와 포토부스
- 커플 연결과 알림

유료는 기록 접근권을 파는 방식이 아니라 이미 쌓인 기록에서 더 예쁜 결과물을 만드는
방식에 집중한다.

우선순위:

1. `우리의 산책북` PDF 또는 이미지 앨범 생성권
2. 다이어리 테마 / 스티커 / 포토부스 프레임팩
3. 기념일 리포트와 공유 카드
4. 결과물 경험을 넓히는 `walkToo+` 이용권

지양하는 방식:

- 과거 기록 잠금
- 지도, 일정, 메모 같은 핵심 흐름 잠금
- 광고 제거 상품
- 영구 무제한 저장 약속
- 결제하지 않으면 기록을 볼 수 없다는 톤

## 3. 상품 방향

### 우리의 산책북

첫 번째 결과물 상품은 좁게 출시한다.

| 항목 | 정책 |
|---|---|
| 결과물 | 선택 기간의 PDF 또는 이미지 앨범 |
| 결제 | 1회성 생성권 |
| 가격대 | 3,900원 ~ 6,900원 |
| 포함 데이터 | 장소, 사진, 질문 답변, 메모, 추억 지도 요약 |
| 운영 | 생성 작업 상태, 재다운로드, 보관 만료일을 명시 |

초기 버전은 한 번에 모든 편집 기능을 넣지 않는다. 기간 선택, 표지, 기록 요약,
다운로드 재시도처럼 결과물 전달에 필요한 흐름부터 검증한다.

### walkToo+ 이용권

`walkToo+`는 구독이 아닌 1회성 이용권이다. 커플 중 한 명이 구매하면 둘이 함께
혜택을 느낄 수 있어야 한다.

현재 앱 기준:

- 우리의 기록 사진 확장
- 고급 다이어리/포토부스 경험 확장
- 산책북 같은 결과물 상품으로 이어지는 진입점 제공
- 구매 복원 지원

표시 문구에서는 `평생`, `영구`, `무제한 저장` 표현을 쓰지 않는다.

## 4. 가격 기준

| 상품 | 현재 기준 |
|---|---:|
| walkToo+ 이용권 fallback | 14,900원 |
| 우리의 산책북 생성권 | 3,900원 ~ 6,900원 |
| 기념일 리포트 | 2,900원 ~ 4,900원 |
| 카드 / 프레임팩 | 1,100원 ~ 2,200원 |

`walkToo+` 가격을 바꾸면 다음을 같은 작업에서 맞춘다.

1. `constants/premium.ts`
2. `docs/revenuecat-setup.md`
3. Apple App Store Connect
4. Google Play Console
5. RevenueCat offering

## 5. 결제 운영

IAP는 RevenueCat을 사용한다. 클라이언트는 결제 성공 후 entitlement를 Supabase에
동기화하고, 운영 안정성이 필요해지면 RevenueCat webhook 기반 서버 동기화로 옮긴다.

결과물 상품은 결제 성공과 파일 생성 성공을 분리해서 추적한다.

1. 결제 또는 생성권 사용
2. 서버 export job 생성
3. 앱에서 생성 중 상태 표시
4. 완료 후 다운로드 제공
5. 실패 시 재생성 또는 환불 대응

## 6. 초기 실행 순서

1. BM 문서와 콘솔 상품 표현을 결과물 중심으로 정렬한다.
2. paywall에서 산책북 진입점을 노출해 구매 맥락을 바꾼다.
3. 산책북 생성 job과 결과물 보관 정책을 구현한다.
4. 실제 커플 10~30쌍에게 결과물 구매 의향과 다운로드 성공률을 검증한다.
5. 반응이 확인된 뒤 기념일 리포트와 프레임팩을 확장한다.

## 7. KPI

초기에는 구독 MRR보다 결과물 구매 신호를 먼저 본다.

- 7일/30일 기록 지속률
- 산책북 진입률
- 산책북 생성 시작률과 완료률
- 결과물 재다운로드 실패율
- 결과물 구매 후 공유/재방문률
- 실제 커플 피드백에서 반복되는 구매 이유

## 8. 결론

walkToo는 추억을 잠가 결제시키지 않는다. 기록은 무료로 쌓이고, 유료는 그 기록을
산책북과 리포트처럼 다시 갖고 싶은 결과물로 바꿔주는 데 집중한다.
