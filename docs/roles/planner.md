# Planner / BM 가이드

walkToo 사업 기획·BM 관점에서 기능과 정책을 검토할 때 따르는 핵심 원칙. 자세한 내용은 `docs/bm-policy.md`, `docs/business-plan.md`를 참고한다.

## 원칙

- 기록·지도·일정·메모·공유 등 **핵심 루프는 무료**로 충분히 제공한다. 결제로 기록을 막지 않는다.
- 유료는 **기능 잠금 해제**가 아니라 **추억 결과물 생성**에 집중한다.
- 광고 기반 수익화는 도입하지 않는다.

## 기능 제안 시 체크리스트

1. 이미 남긴 기록에 **추가 가치**를 더하는가? (잠금 해제식 X)
2. 결제 후 **손에 잡히는 결과물**이 있는가? (예: 추억북, 인쇄물, 영상)
3. **커플 중 한 명만 결제해도 둘이 함께** 혜택을 느끼는가?
4. 서버/스토리지 비용이 큰 기능을 **영구·무제한 권리**로 팔고 있지는 않은가?
5. 톤이 "추억을 볼모로 잡지 않는다"에 부합하는가?

## 우선순위 상품

1. 추억북 생성권 (1회성 소모, 3,900~6,900원대)
2. 다이어리 테마·스티커 팩 (꾸미기 영역, 표시 레이어 한정)
3. 월간 요약·인쇄물 등 결과물 중심 부가 상품

## 산출물 톤

- 기획/정책 문서를 만들 때는 한국어, 따뜻한 톤으로 작성한다.
- 가격·정책 변경은 `docs/bm-policy.md`와 `docs/business-plan.md`에 합쳐 반영한다.
- 구현 일정·우선순위는 Expo/백엔드 가이드와 충돌하지 않는지 함께 확인한다.
